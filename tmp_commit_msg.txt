Mobile-from-scratch: full mobile bundle rewrite + dot-on-hover StatusDot + version fallback

Mobile bundle Phase 3 — replaces the previous Phase 2/2.5 mobile bundle with a
clean design-system rewrite. Desktop bundle remains essentially unchanged
(only Header.tsx touched, only at the four source-status badge locations
plus the version fallback string).

### Added
*   src/components/StatusDot.tsx — new shared desktop+mobile status
    component. Default state is a tiny 8px dot; on hover/focus/tap it
    smoothly expands into a pill containing the label. Five variants:
    live / fallback / done / error / info.
*   src/mobile/mobile.css — full design-token rewrite. Tokens for spacing,
    type, motion, color, shadows — all under .m-root scope so the desktop
    bundle can never pick up mobile rules.
*   src/mobile/MobileTopBar.tsx — sticky glassy 60px top bar with brand,
    contextual title, autosave StatusDot, and Save-as-JSON icon button.
*   src/mobile/MobileTabBar.tsx — 5-tab bottom navigation rail using
    colorful SVG icons from the shared EmojiIcons library; smooth animated
    top accent indicator on tab change.
*   src/mobile/MobileCanvasView.tsx — wraps FlowchartCanvas with a top
    status overlay and a bottom-right zoom FAB stack.
*   src/mobile/MobileEditView.tsx — 4 card-style sections (Selection /
    Clipboard / History / Canvas) with proper disabled-state and a WinUI
    dialog for clear-canvas confirmation.
*   src/mobile/MobileRunView.tsx — StatusDot for execution state (idle /
    running / paused / done), 2x2 action grid (Run/Step/Pause/Stop),
    speed slider, and Notes section.
*   src/mobile/MobileConsoleView.tsx — minimal mobile-safe wrap of the
    existing desktop Console component.
*   src/mobile/MobileToolsView.tsx — 5 card sections (Program/Settings/
    Export/Help/Storage) plus per-row StatusDots for LICENSE/MANUAL/
    CHANGELOG load state.
*   src/mobile/MobileLanguageSheet.tsx — 23-language picker as a bottom
    sheet with FlagIcon SVGs and a translation-accuracy warning.
*   src/mobile/MobileBottomSheet.tsx — minor polish; behavior unchanged.
*   src/mobile/MobileApp.tsx — hoisted RTL_LANGS Set to module scope;
    persists selected tab in localStorage; sets dir='rtl'/'ltr' on the
    mobile root depending on the active language.
*   CONTRIBUTORS.md — rewritten to list PiBOH (creator/maintainer),
    AlexGiulioBerton (active lead collaborator), and lmarena/@arenaai
    (acknowledged model-tooling contributors); documents the
    Co-authored-by: trailer convention used in every commit.

### Changed
*   src/components/Header.tsx — replaced 4 colored source-status chips
    (version, license, manual, changelog) with <StatusDot> calls so they
    no longer take up row width and never actively claim "loaded from
    GitHub" without the user invoking the hover affordance. Version
    fallback string is now '0.0.0-UNKNOWN' so the user is never lied to
    about which version they're running when both fetches fail.
*   .ignore/.assetsai/README.md — stale MIT-License references cleaned
    up to keep dev notes consistent with the current GNU GPL v3 license.

### Fixed
*   MobileToolsView: useEffect cleanup bug. The 3 fetch effects (about /
    manual / changelog) hoisted their cancelled flag out of the async
    IIFE; stale state-update warnings are gone.
*   mobile.css: removed !important from .status-dot[data-open='true']
    so the per-variant pill tint survives on expansion.
*   StatusDot: bumped pill max-width 260 → 320 so longer German and
    Asian license/manual labels don't truncate visibly.
*   MobileTopBar: replaced the full-tree JSON.stringify autosave diff
    with a cheap O(1) check on (statements.length, last-id, programTitle)
    to avoid O(N) work on every keystroke for large flowcharts.
*   mobile.css: .m-view offsets fixed. The previous top: 60px / bottom:
    72px created a 60px dead strip at the top of every mobile view
    because <main> already accounts for the topbar. Now uses inset: 0
    so the view fills <main> completely.

### Architecture invariants (still held)
*   tsc --noEmit clean, npx vitest run 126/126 passed, npm run build
    succeeds.
*   Desktop bundle stays put: only Header.tsx edited at the 4 source-
    status locations plus the version fallback string. MainLayout,
    FlowchartCanvas, Sidebar, Console, Modals, WinUIDialog, BlockNode
    are byte-for-byte identical.
*   Mobile CSS stays scoped under .m-root (zero desktop bleed).
*   State reuse: every mobile component still pulls from useFlow() —
    no duplication of state.
